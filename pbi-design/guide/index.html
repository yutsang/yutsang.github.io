PBI Demo Manual

從CSV匯入、Power Query與TMDL，到互動報表。From CSV import, Power Query and TMDL to an interactive report.

操作順序為匯入來源、合併產品分類、建立模型、核對數字、建立報表，再加入分析指標與互動。The order is: import the sources, merge the product categories, build the model, check the numbers, build the report, then add the analysis measures and interaction.

使用現有CSV，展示名稱統一為 Sales Design Lab。由空白檔開始，逐批建立和驗收模型。已按Windows Desktop實跑結果修訂操作步驟；交付PBIX仍須在接收電腦完成開檔測試。This uses the existing CSV files, with the display name Sales Design Lab throughout. Start from a blank file and build and check the model batch by batch. The steps were revised from a run on Windows Desktop; the handed-over PBIX must still be opened and tested on the receiving computer.

全表行數怎樣核對How to check the full-table row counts

Power Query新增Blank Query，命名QC_Imports，在Advanced Editor貼以下內容。這是檢查query，不取代八張raw。看完後關閉它的Enable load。In Power Query add a Blank Query, name it QC_Imports, and paste the following in Advanced Editor. This is a check query and does not replace the eight raw ones. After reading it, turn off its Enable load.

POWERQUERY
let
    Sources = {
        {"RawHeader", RawHeader, 31465},
        {"RawDetail", RawDetail, 121317},
        {"RawProduct", RawProduct, 504},
        {"RawSubcategory", RawSubcategory, 37},
        {"RawCategory", RawCategory, 4},
        {"RawTerritory", RawTerritory, 10},
        {"RawCostHistory", RawCostHistory, 522},
        {"RawOffer", RawOffer, 16}
    },
    Checks = Table.FromRecords(List.Transform(Sources, each [
        Query = _{0},
        ActualRows = Table.RowCount(_{1}),
        ExpectedRows = _{2},
        ErrorRows = Table.RowCount(Table.SelectRowsWithErrors(_{1}))
    ]))
in
    Checks

ActualRows應逐項等於ExpectedRows，ErrorRows應全0。這個檢查不能代替key唯一／小數部分檢查，但能避免只看前1,000行preview就當完成。ActualRows should equal ExpectedRows item by item, and ErrorRows should all be 0. This check does not replace the key-uniqueness and decimal-part checks, but it stops you calling it done after looking only at the first 1,000 rows of the preview.

停點A：八張query都存在，型別和row counts正確；任何key／日期error先處理，再繼續建立模型。Preview只顯示前幾行不算完成全表驗收。Checkpoint A: all eight queries exist, with the right types and row counts. Fix any key or date error before building the model. A preview that only shows the first few rows is not a full-table check.
