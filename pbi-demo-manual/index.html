PBI Demo Manual

從CSV匯入、Power Query與TMDL，到互動報表。

操作順序為匯入來源、合併產品分類、建立模型、核對數字、建立報表，再加入分析指標與互動。

使用現有CSV，展示名稱統一為 Sales Design Lab。由空白檔開始，逐批建立和驗收模型。已確認的資料控制值列在文末；Windows Desktop 的逐步實跑仍在進行。

文件使用方式

本文件是排練和slides整合的唯一工作稿，檔名為 pbi-demo-manual.md。Prompt、操作程式碼及驗收查詢均直接放在本文件；不需要切換其他本地文件。

從第1步開始操作；已有完成的部分可直接跳到下一步。

完成後應該有甚麼

  • 八張raw staging queries；模型只載入DimProduct、DimTerritory、DimDate、FactSales。
  • 三條active、一對多、single-direction relationships。
  • 一頁報表，有年份／渠道／地區群組篩選、基本cards和territory bar。
  • 用TMDL新增Average Order Value、Gross Margin等measures。
  • 同一張bar可以切Sales／Orders／Average Order Value／Gross Margin，讓你比較不同指標的讀法。
  • Saved Before和After，能核對數字並還原。

A · 開始與匯入

1. 建立空白報表

在Power BI Desktop開Blank report，存 Sales Design Lab - Working.pbix，記錄Desktop完整版本。這一輪使用已完成資料核對的那套CSV。

2. 匯入八張來源

Home → Get data → Text/CSV。第一張選Transform Data；其餘在Power Query內Home → New Source → Text/CSV。

3. 只做必要清洗

  • IDs、OrderQty確認非空值都沒有小數部分，再轉Whole number。文字 771.0 不代表可以忽略實際小數檢查。
  • 金額、單價、折扣轉Decimal number；不在來源步驟逐行Round到兩位。
  • 日期轉Date。若報錯，按實際字串選Using locale；不要Remove Errors。
  • CostHistory.EndDate空字串轉null，代表開放區間。
  • Product.ProductSubcategoryID有209筆空白，保留，不能刪掉對應產品。
  • 不額外平移日期、不填虛構0、不留下臨時預覽filter。

全表行數怎樣核對

Power Query新增Blank Query，命名QC_Imports，在Advanced Editor貼以下內容。這是檢查query，不取代八張raw。看完後關閉它的Enable load。

POWERQUERY
let
    Sources = {
        {"RawHeader", RawHeader, 31465},
        {"RawDetail", RawDetail, 121317},
        {"RawProduct", RawProduct, 504},
        {"RawSubcategory", RawSubcategory, 37},
        {"RawCategory", RawCategory, 4},
        {"RawTerritory", RawTerritory, 10},
        {"RawCostHistory", RawCostHistory, 522},
        {"RawOffer", RawOffer, 16}
    },
    Checks = Table.FromRecords(List.Transform(Sources, each [
        Query = _{0},
        ActualRows = Table.RowCount(_{1}),
        ExpectedRows = _{2},
        ErrorRows = Table.RowCount(Table.SelectRowsWithErrors(_{1}))
    ]))
in
    Checks

ActualRows應逐項等於ExpectedRows，ErrorRows應全0。這個檢查不能代替key唯一／小數部分檢查，但能避免只看前1,000行preview就當完成。

停點A：八張query都存在，型別和row counts正確；任何key／日期error先處理，再繼續建立模型。Preview只顯示前幾行不算完成全表驗收。

B · 親手做一個 Power Query merge

4. 建立DimProduct

右鍵RawProduct → Reference，改名DimProduct。保留ProductID、Name、ProductSubcategoryID。

  1. Home → Merge Queries，右表選RawSubcategory，兩邊點ProductSubcategoryID，Join kind選 Left Outer。
  2. 展開nested欄，只取Name和ProductCategoryID。將展開的Name改Subcategory，原Product的Name改ProductName。
  3. 再Merge RawCategory，以ProductCategoryID連接，Left Outer。只展開Name，改名Category。
  4. Category／Subcategory的null以Unclassified標示。
  5. 最後保留ProductID、ProductName、Category、Subcategory，確認Enable load有開。

驗收：504行，ProductID唯一。209個無分類產品仍保留。

選欄、merge和展開會記錄成M步驟，可在Advanced Editor查看。

Merge與分類欄位的操作補充

  • Merge前，DimProduct和RawSubcategory的ProductSubcategoryID都設Whole Number；再確認RawSubcategory與RawCategory的ProductCategoryID型別相同。兩邊各點對應欄名，Left Outer，不開fuzzy matching。
  • 只保留欄位：Ctrl多選所需欄名，右鍵Remove Other Columns。兩次join完成後，ProductSubcategoryID和ProductCategoryID可以移除，保留最終四欄。
  • 未分類：在Category／Subcategory的Replace Values，以真正的null取代成Unclassified；若使用M，null不帶引號，不能把它當文字"null"。
  • Enable load：Power Query左邊右鍵query，看Enable load前有沒有勾。DimProduct要有勾；raw及QC不要有勾。

5. 看自己的M及TMDL

Advanced Editor看完整DimProduct M，保存文字。Close & Apply後，進TMDL view，在Data pane右鍵DimProduct → Script TMDL to → New tab／Clipboard（依版本名稱）。

只找三個位置：column、dataType、partition下面的M。先不要重新Apply整張DimProduct，因為它已經建立。

若script開頭是relationship而非table DimProduct，是選到了關聯。右側Data pane上方切Tables，右鍵整張DimProduct表名再script；也可把表名拖入編輯區。

這不是把同一個merge再做一次，而是看同一個物件的文字定義。

C · 建立其餘模型

6. 分批建立模型

以下分四批操作。每批先貼TMDL、Preview、Apply，再執行驗收查詢。Prompt可用作練習；直接操作時複製TMDL區塊即可。

目前位置

已完成DimProduct的Power Query merge，並看過它的table script。接下來不再手動建立同樣的新tables，直接套下列TMDL。

先在Power Query確認RawHeader、RawDetail、RawProduct、RawSubcategory、RawCategory、RawTerritory、RawCostHistory、RawOffer及QC_Imports的Enable load關閉；DimProduct開啟，再Close & Apply。圖上若仍有raw模型表及自動關聯，這步會把未需載入的來源表移出模型，並保留staging queries供M引用。

每批相同操作

  1. 在TMDL view按底部＋開新tab。
  2. 貼入該批「TMDL程式碼」完整內容。不要貼入上一個仍有DimProduct script的tab而串成兩個command。
  3. Preview確認只有該批物件改動，然後Apply。
  4. 有新table／M時回Home→Refresh；只Apply不代表已讀入資料。
  5. 用該批驗收查詢核對，再到下一批。

如果目前同名table已存在，先不要再套完整table的createOrReplace，保留當前版本確認再處理；否則可能替換table的children。

第6.1批 · DimTerritory＋DimDate

Prompt

TEXT
請為Sales Design Lab新增DimTerritory及DimDate，回傳一段完整可直接貼入Power BI TMDL view的createOrReplace腳本，不包含省略號。
現有DimProduct和raw staging queries保持不變。RawTerritory已存在，欄位TerritoryID、Name、Group；可在M直接引用。
DimTerritory：選這三欄，TerritoryID為整數，Name改Territory，Group為文字。
DimDate：用M產生2023-01-01至2026-12-31的完整日曆，Date為日期，Year及MonthNumber為整數，MonthLabel為英文月份簡寫，YearMonth為yyyy-MM；MonthLabel按MonthNumber排序。

TMDL程式碼

TMDL
createOrReplace

	table DimTerritory
		column TerritoryID
			dataType: int64
			sourceColumn: TerritoryID
			summarizeBy: none
		column Territory
			dataType: string
			sourceColumn: Territory
			summarizeBy: none
		column Group
			dataType: string
			sourceColumn: Group
			summarizeBy: none

			mode: import
			source =
				let
				    Source = Table.SelectColumns(#"RawTerritory", {"TerritoryID", "Name", "Group"}),
				    Typed = Table.TransformColumnTypes(Source, {{"TerritoryID", Int64.Type}, {"Name", type text}, {"Group", type text}}),
				    Final = Table.RenameColumns(Typed, {{"Name", "Territory"}})
				in
				    Final

	table DimDate
		column Date
			dataType: dateTime
			sourceColumn: Date
			summarizeBy: none
			formatString: yyyy-MM-dd
		column Year
			dataType: int64
			sourceColumn: Year
			summarizeBy: none
		column MonthNumber
			dataType: int64
			sourceColumn: MonthNumber
			summarizeBy: none
		column MonthLabel
			dataType: string
			sourceColumn: MonthLabel
			summarizeBy: none
			sortByColumn: MonthNumber
		column YearMonth
			dataType: string
			sourceColumn: YearMonth
			summarizeBy: none

			mode: import

				    Typed = Table.TransformColumnTypes(Source, {{"Date", type date}}),
				    AddYear = Table.AddColumn(Typed, "Year", each Date.Year([Date]), Int64.Type),
				    AddMonth = Table.AddColumn(AddYear, "MonthNumber", each Date.Month([Date]), Int64.Type),
				    AddLabel = Table.AddColumn(AddMonth, "MonthLabel", each Date.ToText([Date], [Format="MMM", Culture="en-US"]), type text),

第6.2批 · FactSales

Prompt

TEXT
請只新增FactSales，回傳完整可直接貼入TMDL view的createOrReplace腳本，包含所有columns及完整M partition，不包含省略號。
現有RawDetail、RawHeader、RawCostHistory、RawOffer為staging M queries，可直接引用。其他已建tables不變。
一行一個SalesOrderDetailID。RawDetail選SalesOrderID、SalesOrderDetailID、ProductID、SpecialOfferID、OrderQty、LineTotal。
按SalesOrderID Left Outer join RawHeader，只帶OrderDate、ShipDate、CustomerID、TerritoryID、OnlineOrderFlag。日期轉Date，保留全部明細；不帶Header金額。
Channel由OnlineOrderFlag=1轉Online，否則Reseller。
CostMatchDate優先ShipDate，空白fallback OrderDate。RawCostHistory欄ProductID、StartDate、EndDate、StandardCost，空字串EndDate先轉null，再視開放區間。
按ProductID nested join成本表，在nested table用StartDate<=CostMatchDate<=EndDate配對，保留CostMatchCount；只在唯一匹配時HistoricalCost=OrderQty*StandardCost，其餘null。CostMatchStatus區分OK、Missing cost、Multiple matches，不展開所有成本版本。
Left Outer join RawOffer，按SpecialOfferID取得DiscountPct，以>0建立IsDiscounted，不再次扣交易折扣。
最終欄位LineID、OrderID、CustomerID、ProductID、TerritoryID、OrderDate、Channel、Quantity、NetSales、HistoricalCost、CostMatchCount、CostMatchStatus、IsDiscounted。
LineID來自SalesOrderDetailID，OrderID來自SalesOrderID，Quantity來自OrderQty，NetSales來自LineTotal。ID/Quantity/count/flag整數，金額小數，日期dateTime，文字string。
不要新增relationships、measures或visuals。

TMDL
createOrReplace

	table FactSales
		column LineID
			dataType: int64
			sourceColumn: LineID
			summarizeBy: none
		column OrderID
			dataType: int64
			sourceColumn: OrderID
			summarizeBy: none
		column CustomerID
			dataType: int64
			sourceColumn: CustomerID
			summarizeBy: none
		column ProductID
			dataType: int64
			sourceColumn: ProductID
			summarizeBy: none
		column TerritoryID
			dataType: int64
			sourceColumn: TerritoryID
			summarizeBy: none
		column OrderDate
			dataType: dateTime
			sourceColumn: OrderDate
			summarizeBy: none
			formatString: yyyy-MM-dd
		column Channel
			dataType: string
			sourceColumn: Channel
			summarizeBy: none
		column Quantity
			dataType: int64
			sourceColumn: Quantity
			summarizeBy: none
		column NetSales
			dataType: double
			sourceColumn: NetSales
			summarizeBy: none
		column HistoricalCost
			dataType: double
			sourceColumn: HistoricalCost
			summarizeBy: none
		column CostMatchCount
			dataType: int64
			sourceColumn: CostMatchCount
			summarizeBy: none
		column CostMatchStatus
			dataType: string
			sourceColumn: CostMatchStatus
			summarizeBy: none
		column IsDiscounted
			dataType: int64
			sourceColumn: IsDiscounted
			summarizeBy: none
		partition FactSales = m
			mode: import
			source =
				let
				    D = Table.TransformColumnTypes(Table.SelectColumns(RawDetail,{"SalesOrderID","SalesOrderDetailID","ProductID","SpecialOfferID","OrderQty","LineTotal"}),{{"SalesOrderID",Int64.Type},{"SalesOrderDetailID",Int64.Type},{"ProductID",Int64.Type},{"SpecialOfferID",Int64.Type},{"OrderQty",Int64.Type},{"LineTotal",type number}}),
				    H0 = Table.SelectColumns(RawHeader,{"SalesOrderID","OrderDate","ShipDate","CustomerID","TerritoryID","OnlineOrderFlag"}),
				    H1 = Table.TransformColumnTypes(H0,{{"SalesOrderID",Int64.Type},{"CustomerID",Int64.Type},{"TerritoryID",Int64.Type},{"OnlineOrderFlag",Int64.Type}}),

				    J = Table.NestedJoin(D,{"SalesOrderID"},H,{"SalesOrderID"},"Header",JoinKind.LeftOuter),
				    EH = Table.ExpandTableColumn(J,"Header",{"OrderDate","ShipDate","CustomerID","TerritoryID","OnlineOrderFlag"}),
				    Channel = Table.AddColumn(EH,"Channel",each if [OnlineOrderFlag] = 1 then "Online" else "Reseller",type text),
				    MatchDate = Table.AddColumn(Channel,"CostMatchDate",each if [ShipDate] = null then [OrderDate] else [ShipDate],type date),
				    C0 = Table.TransformColumnTypes(Table.SelectColumns(RawCostHistory,{"ProductID","StartDate","EndDate","StandardCost"}),{{"ProductID",Int64.Type},{"StandardCost",type number}}),
				    C = Table.Buffer(Table.TransformColumns(C0,{{"StartDate",each Date.From(_, "en-US"),type date},{"EndDate",each if _ = null or _ = "" then #date(9999,12,31) else Date.From(_, "en-US"),type date}})),
				    JC = Table.NestedJoin(MatchDate,{"ProductID"},C,{"ProductID"},"History",JoinKind.LeftOuter),
				    Matches = Table.AddColumn(JC,"Matches",each let d=[CostMatchDate] in Table.SelectRows([History],(row)=>row[StartDate]<=d and d<=row[EndDate]),type table),
				    Count = Table.AddColumn(Matches,"CostMatchCount",each Table.RowCount([Matches]),Int64.Type),
				    Cost = Table.AddColumn(Count,"HistoricalCost",each if [CostMatchCount]=1 then [OrderQty]*[Matches]{0}[StandardCost] else null,type nullable number),
				    Status = Table.AddColumn(Cost,"CostMatchStatus",each if [CostMatchCount]=1 then "OK" else if [CostMatchCount]=0 then "Missing cost" else "Multiple matches",type text),
				    O = Table.TransformColumnTypes(Table.SelectColumns(RawOffer,{"SpecialOfferID","DiscountPct"}),{{"SpecialOfferID",Int64.Type},{"DiscountPct",type number}}),
				    JO = Table.NestedJoin(Status,{"SpecialOfferID"},O,{"SpecialOfferID"},"Offer",JoinKind.LeftOuter),
				    EO = Table.ExpandTableColumn(JO,"Offer",{"DiscountPct"}),
				    Discount = Table.AddColumn(EO,"IsDiscounted",each if [DiscountPct]=null then null else if [DiscountPct]>0 then 1 else 0,Int64.Type),
				    Rename = Table.RenameColumns(Discount,{{"SalesOrderID","OrderID"},{"SalesOrderDetailID","LineID"},{"OrderQty","Quantity"},{"LineTotal","NetSales"}}),
				    Final = Table.SelectColumns(Rename,{"LineID","OrderID","CustomerID","ProductID","TerritoryID","OrderDate","Channel","Quantity","NetSales","HistoricalCost","CostMatchCount","CostMatchStatus","IsDiscounted"})
				in
				    Final

7. 逐批Review、Apply、Refresh

每批在TMDL view新tab檢查。用Preview看改動範圍，確認沒有意外刪掉現有物件，再Apply。

	ref table FactSales

			formatString: #,0

		measure 'W Sales2025' = CALCULATE([Sales], REMOVEFILTERS(DimDate), DimDate[Year]=2025)
			formatString: #,0.00

		measure 'W GP2025' = CALCULATE([Gross Profit], REMOVEFILTERS(DimDate), DimDate[Year]=2025)
			formatString: #,0.00

		measure 'W GM2025' = DIVIDE([W GP2025], CALCULATE([Costed Sales],REMOVEFILTERS(DimDate),DimDate[Year]=2025))
			formatString: 0.0%

		measure 'W Sales2024' = CALCULATE([Sales], REMOVEFILTERS(DimDate), DimDate[Year]=2024)
			formatString: #,0.00

		measure 'W Sales YoY' =
				VAR Y = SELECTEDVALUE(DimDate[Year],2025)
				VAR LastDate = CALCULATE(MAX(FactSales[OrderDate]),REMOVEFILTERS())
				VAR EndDate = IF(Y=YEAR(LastDate),LastDate,DATE(Y,12,31))
				VAR CurrentValue = CALCULATE([Sales],REMOVEFILTERS(DimDate),DATESBETWEEN(DimDate[Date],DATE(Y,1,1),EndDate))

				RETURN IF(Y>=2025 && NOT ISBLANK(PriorValue),DIVIDE(CurrentValue-PriorValue,PriorValue))
			formatString: +0.0%;-0.0%;0.0%

		measure 'W GP YoY' =
				VAR Y = SELECTEDVALUE(DimDate[Year],2025)
				VAR LastDate = CALCULATE(MAX(FactSales[OrderDate]),REMOVEFILTERS())
				VAR EndDate = IF(Y=YEAR(LastDate),LastDate,DATE(Y,12,31))
				VAR CurrentValue = CALCULATE([Gross Profit],REMOVEFILTERS(DimDate),DATESBETWEEN(DimDate[Date],DATE(Y,1,1),EndDate))
				VAR PriorValue = CALCULATE([Gross Profit],REMOVEFILTERS(DimDate),DATESBETWEEN(DimDate[Date],DATE(Y-1,1,1),EDATE(EndDate,-12)))
				RETURN IF(Y>=2025 && NOT ISBLANK(PriorValue),DIVIDE(CurrentValue-PriorValue,PriorValue))
			formatString: +0.0%;-0.0%;0.0%

		measure 'W GM Change' =
				VAR Y = SELECTEDVALUE(DimDate[Year],2025)
				VAR LastDate = CALCULATE(MAX(FactSales[OrderDate]),REMOVEFILTERS())
				VAR EndDate = IF(Y=YEAR(LastDate),LastDate,DATE(Y,12,31))
				VAR CurrentValue = CALCULATE([Gross Margin],REMOVEFILTERS(DimDate),DATESBETWEEN(DimDate[Date],DATE(Y,1,1),EndDate))
				VAR PriorValue = CALCULATE([Gross Margin],REMOVEFILTERS(DimDate),DATESBETWEEN(DimDate[Date],DATE(Y-1,1,1),EDATE(EndDate,-12)))

			formatString: #,0.00

			formatString: 0.0

		measure 'W Lowest Month' =

				VAR Best = TOPN(1,FILTER(T,NOT ISBLANK([@Sales])),[@Sales],ASC,[Value],ASC)
				RETURN IF(COUNTROWS(Best)=0,"—",FORMAT(DATE(2025,MAXX(Best,[Value]),1),"MMM","en-US"))

		measure 'W Top3 Month Share' =

				RETURN DIVIDE(SUMX(TOPN(3,T,[@Sales],DESC,[Value],ASC),[@Sales]),[W Sales2025])
			formatString: 0.0%

		measure 'W Actual Lock Month' = 6
			formatString: 0

		measure 'W Growth Factor' = DIVIDE([W Sales2025],[W Sales2024])
			formatString: 0.00x

			formatString: #,0.00

		measure 'W Base26' =

			formatString: #,0.00

			formatString: 0.0%

		measure 'W Uplift26' = [W Base26]*[W Plan Rate]
			formatString: #,0.00

		measure 'W Plan Value' = IF(NOT ISBLANK([W Actual26]),[W Actual26],[W Base26]+[W Uplift26])

			formatString: #,0.00
