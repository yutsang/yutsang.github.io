Skills for Real Engineers — mattpocock/skills

Matt Pocock's own daily .agents directory, published. Built around three failure modes — misalignment, verbosity, and code that doesn't actually run — each with a skill attached: /grill-me forces the agent to interrogate you before it builds anything; a shared CONTEXT.md closes the jargon gap between you and it. Worth installing from the source rather than copying it here. Stock analysis · built by me股票分析 · 自行開發

Equity Research

Built around one rule: the model never calculates. Every forecast and DCF number comes out of deterministic code, with fail-closed validation, point-in-time snapshots, and a full source ledger. Run end to end on SK Hynix. 整套 skill 只圍繞一條規則：模型從不計算，forecast 與 DCF 數字全部由 deterministic code 產生，搭配 fail-closed 驗證、point-in-time 快照，以及完整的來源紀錄。在 SK hynix 身上完整跑過一次。

Free · SKILL.md download · methodology only, bring your own pipeline 免費 · SKILL.md 可下載 · 只有方法論，計算引擎要自己接上

Code review程式碼審查

code-review

Reviews a diff along two axes in parallel — does it follow the repo's coding standards, and does it actually match the spec it was meant to implement — then reports both side by side. Ships with a built-in Fowler code-smell checklist as a baseline. 沿兩條軸線平行審查一個 diff——係咪跟返個 repo 嘅程式碼規範、同埋係咪真係做到個 spec 要求嘅嘢——然後將兩邊結果並排報告。內建 Fowler code-smell checklist 做底線標準。
