Skills for Real Engineers — mattpocock/skills

Matt Pocock's own daily .agents directory, published. Built around three failure modes — misalignment, verbosity, and code that doesn't actually run — each with a skill attached: /grill-me forces the agent to interrogate you before it builds anything; a shared CONTEXT.md closes the jargon gap between you and it. Worth installing from the source rather than copying it here. Matt Pocock 公開了自己的 .agents 設定，並以溝通偏差、內容冗長和程式未能執行等問題整理相應 skills。/grill-me 會在開始前釐清需求；共用的 CONTEXT.md 則協助統一術語。建議直接從原始 repo 安裝。

Stock analysis · built by me股票分析 · 自行開發

Equity Research

Built around one rule: the model never calculates. Every forecast and DCF number comes out of deterministic code, with fail-closed validation, point-in-time snapshots, and a full source ledger. Run end to end on SK Hynix. 這個 skill 將數值計算交給確定性程式處理，再以 fail-closed 驗證、point-in-time 快照和來源紀錄檢查分析結果。頁面附有 SK hynix 示例。

Planning interview規劃訪談

grill-me

Before Claude starts on anything non-code — a plan, a design, a decision — this runs a relentless interview to pressure-test it first. Cheap insurance against building the wrong thing. 在 Claude 處理計劃、設計或決策前，這個 skill 會先透過提問檢視需求和假設，減少方向理解錯誤的機會。

Code review程式碼審查

code-review

Reviews a diff along two axes in parallel — does it follow the repo's coding standards, and does it actually match the spec it was meant to implement — then reports both side by side. Ships with a built-in Fowler code-smell checklist as a baseline. 從 repo 的程式規範和需求符合度兩方面審查 diff，並分開列出結果。另附 Fowler code-smell 清單作為檢查參考。
